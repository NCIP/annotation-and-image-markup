I.26/25/13

Add a notification about ANIVATR as follows.

The AIM Toolkit consists of the AIM C++ software library and a program called ANIVATR. The ANIVATR software application validates AIM annotations and transcodes them between AIM XML documents and AIM DICOM SR objects. ANIVATR does not have a capability to convert any XML documents or DICOM SR objects to AIM XML documents and AIM DICOM SR objects. 		HPat and CarolynFinished
