General

  This week was short due to 4th of July celebration.

Provided email and teleconference support to external AIM users.
ClearCanvasWe had first contact with ClearCanvas engineer this week. The engineer will be assisting AIM team on code issues and technical aspects of the work via weekly ½ hour meetings and emails as needed.

  Windows debug and release builds are buildable with CMake.

AIM library 4.1

  Ongoing QA testing

New test bundle is coming this week that will allow testing of Linux and Windows changes.  
AIM Workstation

  For 3.5.0.1, the release is done. Remaining work is an official release announcement.

  For 4.0, the latest build has been released to QA. An issue with importing AIM Annotations was identified and fixed. We are waiting on full QA results.

For 4.1, we are still working on the new infrastructure for annotation tracking within the workstation (AIM annotation cache and AIM Annotation Monitor). (This new infrastructure will allow us to track additions and removal of individual annotations from DICOM studies. Different plugins will use these facilities to get updates when annotations change in a study). The plan is to have an initial QA release within the next week or so.  
AIM Data Service 2.0 IntegrationAIM Data Service implementation is done.

Internal testing continues. This week we should be able to release a build that contains the plugin to QA

Performed additional AIM DOS schema testing.

Add a notification about ANIVATR as follows.

 “The AIM Toolkit consists of the AIM C++ software library and a program called ANIVATR. The ANIVATR software application validates AIM annotations and transcodes them between AIM XML documents and AIM DICOM SR objects. ANIVATR does not have a capability to convert any XML documents or DICOM SR objects to AIM XML documents and AIM DICOM SR objects.” 		HPat and CarolynFinished
